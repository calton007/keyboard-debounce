# KeyboardDebounce 0.3 架构

## 模块与所有权

| 模块 | 所有权与接口 |
|---|---|
| Rust `engine` | 纯过滤状态机，输入物理键事件，返回同步决策；不调用操作系统 |
| Rust `runtime` | 唯一设置、学习、模式和版本状态；处理设置变化与过期检测结果 |
| Rust `platform` | Windows API 和 unsafe、SID 会话互斥锁、钩子、热键、进程枚举、注册表、原子替换 |
| Rust `persistence` | 双文件 Schema 1 JSON、备份恢复、唯一写入者与退避 |
| Rust `app` | Tauri 命令、托盘、按需窗口、后台协调和 UI 事件投影 |
| React | 界面与草稿状态；业务值来自 Rust 快照 |

安装 `WH_KEYBOARD_LL` 的线程独占引擎和按键配对状态，以 Windows 消息循环持续处理输入。25ms 定时器处理有限批次控制命令；回调不写磁盘、不枚举进程、不调用 IPC、不等待前端锁。钩子回调的 panic 在 FFI 内拦截，原始故障随后进入运行态并停用过滤。

后台协调线程读取不可变快照，每秒枚举一次进程，串行执行保存和手动刷新。检测结果携带配置版本，过期结果丢弃并重新检测。设置/学习各自有单调版本；写入只确认对应版本，旧保存完成不能清除新版本的脏状态。普通统计 5 秒检查点，阈值调整立即请求写入，失败 1–60 秒退避。

## 输入行为

物理身份为 VK + scan code + Extended，学习按 VK 保存。短间隔判断采用最后观察的 KeyDown，阈值包含等号；Windows DWORD 时间回绕使用 wrapping subtraction。长按同时覆盖最初被放行与最初被拦截的持续按住。

配对状态独立于引擎时间线。暂停或游戏模式变化保留待拦截 KeyUp；已交付的按住直到物理释放前直通。忽略移除该 VK 的学习，但保留最后观察时间及待配对释放；其他键不受影响。软件注入事件不能消费物理键的待配对状态。

学习规则及数值默认见 README。纯 Rust 回归测试和 `tests/parity.rs` 固定行为，后者重放原 C# 过滤器输出的 5,400 条合成事件。

## 命令与界面

普通设置通过 `SettingsPatch` 修改；热键、自启、启停、EXE 名单、按键规则和学习重置使用专门命令。后端校验后串行应用；前端也串行提交更改，不将完整旧快照写回。热键先注册新组合，再注销旧组合，失败保持旧绑定。启动热键不可用时禁止防抖。

Rust DTO 使用 ts-rs 生成 `frontend/generated`。`state-changed` 传递版本化快照；前端先订阅再读取，拒绝旧版本。统计最多每 250ms 合并推送；模式、保护与保存错误变化及时推送。无窗口时停止 UI 推送。

五页在窗口内保持挂载，隐藏页不重新初始化交互状态。数字框焦点内保留草稿，后台刷新不覆盖输入。列表只有显式搜索、筛选、排序或刷新才改变成员与顺序，后台统计更新已有行。窗口关闭销毁 WebView，再打开时回到概览；静默启动不创建窗口，托盘退出才结束事件循环。

紧凑界面采用 64px 导航栏、20px 内容内距、16px 分组间距、36px 表单控件和 40px 表格行。概览只保留一份参数摘要和最近事件；设置按行对齐，游戏 EXE 和按键表格填满剩余高度。卡片没有固定最小高度，五页不显示常驻说明、操作教学或实现细节；错误、真实状态、输入校验、维护确认和无障碍标签继续保留。只在防抖实际生效时突出活动模式。说明文档位于 README，不移入隐藏帮助。

权限仅允许主窗口订阅本地事件，系统操作由范围明确的 Rust 命令执行。没有通用 shell、任意路径读写或远程页面权限。

## 数据与升级

新目录 `%APPDATA%\KeyboardDebounceTauri`，不读取旧 .NET 数据。配置和学习是两个独立原子文件，不承诺跨文件事务；忽略规则优先于残留学习记录。每个文件含 schemaVersion=1，字段 camelCase，UTC 时间为 ISO 8601。

损坏内容先隔离，恢复有效备份；无有效设置时保持停用。保存不会用损坏主文件覆盖有效备份。恢复与保存错误都必须可见。退出先冻结输入、获取最终快照，再保存两份文件并释放核心资源；失败用原生对话框报告。

复用 `Local\KeyboardDebounce-{用户SID}` 防止旧版与新版同时挂钩。首次启动只读取现有自启项；只有用户主动切换自启才修改 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run\KeyboardDebounce`。命令必须指向当前程序。

## 构建与发布

Windows x64 / Rust MSVC；Node 22、npm、Vite。Cargo 包版本是 0.3.0 的唯一真源。NSIS 当前用户安装，WebView2 downloadBootstrapper；便携版使用已有运行时。保留图标、LICENSE 与既有设计素材。

验证入口 `scripts/verify.ps1`；发布入口 `scripts/publish.ps1`。发布四文件集合在暂存目录完成哈希及 ZIP 内容校验后替换；发布锁防止并发发布，备份支持失败回滚，被占用文件报告精确路径。没有自动更新、签名凭据或跨平台适配。
